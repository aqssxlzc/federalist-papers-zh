# 译者前言

## 一、这部书是什么

《联邦党人文集》不是一部书斋里的政治学著作，而是一场迫在眉睫的政治斗争的产物。1787年9月，费城制宪会议草成《美利坚合众国宪法》，送交十三州批准。纽约州的反对力量最强，州长乔治·克林顿一派控制着州议会和大部分报纸。亚历山大·汉密尔顿于是联络约翰·杰伊、詹姆斯·麦迪逊，以罗马共和派英雄“普布利乌斯”为化名，在纽约的报纸上连续发表文章，逐条为宪法辩护、逐条驳斥反对意见。从1787年10月到1788年8月，共刊出八十五篇；其中七十七篇先见报，八篇（第78—85篇）先收入当年出版的麦克莱恩（McLean）两卷本。

这些文章当时并未扭转纽约的民意——纽约州代表大会最终仅以30票对27票、并附多项修正建议才批准宪法——但它们把一场地方性的批准之争，提升为关于共和政体原理的普遍讨论。此后两百年，凡讨论分权、制衡、联邦主义、派系、司法审查、行政活力的人，都绕不开这本书。它既是最早的宪法解释文本，也是现代政治理论的经典。

## 二、底本与体例

本译以 Project Gutenberg 电子文本（eBook #18）为底本，参校 1788 年麦克莱恩版及通行的 Gideon 版、Rossiter 版编次。底本偶有排印讹误（如第59篇篇号误作 LIV、第70篇收入两个略有差异的文本），译文据通行校本处理，并在相关篇章的注释中说明。

翻译体例是**现代汉语学术直译**：

- 原文每一段都完整译出，不删节、不改写、不把论证压缩成提要。
- 十八世纪英文的长句，按中文意群切开，但因果、让步、转折、并列的逻辑关系一律保留。
- 专名、术语按书末《统一译名表》统一；同一概念不因上下文不同而随意换词。
- 古典引文、历史典故、法律术语出注；常识性内容不注。
- 每篇前有“背景导读”，交代写作时机、论战对手与在全书中位置；后有“作者倾向与观点”，说明该篇的作者归属、核心主张与思想脉络。这两部分供初读者使用，不作论文式的繁琐考证。

## 三、作者归属

八十五篇的署名都是“普布利乌斯”，真实作者为汉密尔顿、麦迪逊、杰伊三人。传统归属是：汉密尔顿五十一篇，麦迪逊二十六篇，杰伊五篇，第18—20篇为汉密尔顿与麦迪逊合作。其中有两组篇目长期存在争议：

- 第18—20篇：原署名“汉密尔顿与麦迪逊”。麦迪逊晚年的札记称由汉密尔顿执笔、取材于自己的笔记；今多从此说。
- 第49—58、62—63篇：原署名“汉密尔顿或麦迪逊”。两人晚年各自开列的篇目互相冲突；20世纪60年代 Mosteller 与 Wallace 的文体统计分析支持麦迪逊，今通行本归麦迪逊。

本译本按今通行归属处理，在各篇“作者倾向与观点”中一句说明，不展开考证。读者若见旧译本把第49—58篇归给汉密尔顿，那是沿用了19世纪的旧说。

## 四、如何读这本书

《联邦党人文集》的论证是有计划的，不是八十五篇散论。第1篇列出纲目，其后大致分为四段：

1. **联邦的效用**（第2—14篇）：对外防务、州际和平、商业、税收、常备军与民兵。杰伊写外来威胁，汉密尔顿写州际纷争与商业，麦迪逊写广土众民与派系。
2. **邦联的缺陷**（第15—22篇）：无征税权、无强制力、无商业规制权、无统一外交，并以历史上的邦联（希腊、瑞士、荷兰、德意志）为鉴。
3. **新宪法的原理**（第23—46篇）：联邦需要什么权力、这些权力如何授予、州与联邦如何并存。第37—46篇出自麦迪逊，是全书理论密度最高的部分。
4. **政府各部门的构造**（第47—85篇）：众议院、参议院、总统、法院，以及各部门之间的制约与平衡。第47—51篇论分权，第52—58篇论众议院，第62—63篇论参议院，第67—77篇论总统，第78—83篇论司法，第84篇答“无权利法案”之讥，第85篇作结。

初读者若时间有限，可先读第1、10、39、47、51、70、78、84、85篇；这九篇构成全书的骨架。但若想理解论证的细密处，仍须按顺序读——普布利乌斯的许多回答，是针对前一篇留下的问题而发的。

## 五、一点提醒

《联邦党人文集》是辩护文字，不是中立的社会科学分析。它有意强调联邦的好处、淡化联邦权力的风险；它对奴隶制、印第安人、妇女、无产者的处理，反映了十八世纪有产白人社群的局限。第54篇为五分之三妥协辩护的种族主义语言，第42篇对奴隶贸易的默许，都是今天读来必须直面的内容。译者不替作者掩饰，也不以今天的标准简单定罪；译文照原意译出，必要处加注说明。

同样，书中的“人民”“自由”“共和”都有特定含义。普布利乌斯所说的“人民”，主要指有政治参与资格的白人有产者；“共和”指代议制政府，而非直接民主；“自由”首先指人身与财产的安全、免于任意权力的保障。把这些词照字面读成现代汉语中的对应词，会错过许多东西。

愿这本译本帮助中文读者进入那场关于共和国命运的论战，并从中看见：一部宪法的生命，不仅在于文本，更在于一代人如何争论它、解释它、为它承担后果。

## 六、关于本译的生成方式

本译的初稿由人工智能辅助完成，随后统一术语与体例，并对重点篇章逐段复核。人工智能可以承担繁重的初译与资料整理，但判断、取舍与最终文字责任仍由译者承担。读者若发现误译、漏译或史实错误，欢迎指正。

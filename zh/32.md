# 第三十二篇　续论征税的一般权力（二）

*No. 32 — The Same Subject Continued*

> 原载《每日广告报》（The Daily Advertiser），1788年1月2日；署名“普布利乌斯”。

## 背景导读

1788年1月2日，本篇刊于《每日广告报》。第30、31篇从原则上证成联邦的一般征税权，本篇转入宪法文本的严格解释。反联邦党人——尤其是“布鲁图斯”——主张：国会的一般征税权、最高条款与必要而适当条款合在一起，会使各州征税权名存实亡；联邦可以借口“与联邦税冲突”废除州税，最终垄断一切税源。汉密尔顿则从“排他授予”的三种情形入手，论证除进出口关税外，各州与联邦的征税权是并行且同等的；宪法第一条第十节对州征收进出口关税的禁止，恰恰反证各州保留其余一切税权。这是全组文章中最具律师色彩的一篇，也为后世“并行权力”提供了经典解释，其影响及于美国宪法学中的“联邦优先”与“州保留权力”之争。后来的论者常引本篇为州保留权力的依据，尽管汉密尔顿的本意是证明联邦权力已经足够。这一解释路径也说明，宪法为何只对进出口税设禁，而不对内部税设禁。

## 作者倾向与观点

本篇出自汉密尔顿手笔。其核心主张是：解释宪法不能从“可能的不便”推出“宪法上的无权”；除明文排他授予联邦者外，各州主权权利完整保留。论证策略有三：先作出重大让步，承认各州应有独立而不可控制的财源，以解除对手的道德优势；再以“排他授予三情形”的框架把问题化为文本归类，证明征税权不在其列；最后以“否定中寓肯定”的普通法解释，把禁止州征进出口税读成对州其余税权的确认。这体现他作为律师的文本主义与结构解释，也服务于政治目的——以看似克制、严格的法律解释，锁定联邦征税权的广泛性。与麦迪逊在第39篇对“联邦性质”与“全国性质”的精细区分相比，汉密尔顿此处更强调联邦权力在实际运作中的完整性。他并不否认并行税制可能带来政策摩擦，但坚持摩擦不等于无权，这一区分是全篇的关键。因此，本篇的“让步”是策略性的，而非原则性的。

## 译文

致纽约州人民：

虽然我认为，联邦拥有控制各州筹款方式的权力，并不会真正产生人们似乎为州政府担心的那些后果；因为我确信，人民的意向、激怒州政府怨恨的极大危险，以及对地方行政处理地方事务之效用和必要性的信念，将构成一道完整屏障，防止这种权力被压迫性地使用。然而，我在此愿意充分承认这样一条推理的正当性：各州应当拥有独立而不可控制的权力，以筹集自己的财政收入来满足自身需要。作出这一让步之后，我断言：除了对进出口货物征收关税这一唯一例外，根据制宪会议方案，各州将在最绝对、最无条件的意义上保留这项权力；全国政府若企图缩减它们行使这项权力，那就是粗暴地攫取权力，为它宪法的任何条款所不许。

把各州完全合并为一个完整的全国主权，将意味着各部分完全处于从属地位；无论它们还保留什么权力，都将完全取决于总的意志。但制宪会议方案只追求部分的联合或合并，因此州政府显然保留它们以前拥有的一切主权权利，只要这些权利没有因该文件而被“排他地”授予合众国。这种州主权的排他授予，或者毋宁说让渡，只存在于三种情况：宪法以明文授予联邦一项排他权力；宪法在一处授予联邦一项权力，而在另一处禁止各州行使同类权力；宪法授予联邦一项权力，而各州若拥有类似权力，将与之绝对而完全地“矛盾”和“抵触”。我用这些词，是为了把最后一种情况与另一种看似相似、实则根本不同的情况区分开来；我指的是，行使并行管辖权可能偶尔在某一行政分支的“政策”上产生冲突，但在宪法权力上并不含有任何直接矛盾或抵触。联邦政府享有排他管辖权的这三种情况，可以用以下实例说明：第一条第八节倒数第二款明确规定，国会对划作政府所在地的地区行使“排他立法权”。[^1] 这对应第一种情况。同节第一款授权国会“征收并收取税款、关税、进口税和消费税”；同条第十节第二款宣布，“任何州未经国会同意，不得对进出口货物征收任何进口税或关税，但为执行其检查法者除外”。[^2] 由此便产生联邦对进出口货物征税的排他权力，但上述例外除外；不过这项权力又被另一款所缩减，该款规定不得对任何州输出的货物征税；由于这一限制，它现在只及于“进口关税”。这对应第二种情况。第三种情况见于下列条款：国会应有权“在合众国全境制定统一的归化规则”。这必然是排他的；因为如果各州有权制定“各自不同”的规则，就不可能有“统一”的规则。

有一种情况也许会被认为与后一种相似，但实际上大不相同，它关系到眼前讨论的问题。我指的是对进出口货物以外的一切物品征税的权力。我主张，这显然是合众国与各州并行且同等的权力。授予条款中显然没有任何表述使这项权力在联邦成为排他的。也没有任何独立条款或句子禁止各州行使它。事实远非如此，从对州征收进出口关税的限制中，倒可以推出一个明白而有决定性的相反论据。这项限制意味着承认：如果没有写入这项限制，各州就会拥有它所排除的权力；它还意味着进一步承认：就其他一切税而言，各州的权力依然未减。从任何其他角度看，这项限制既无必要又危险：无必要，因为如果授予联邦征收此类关税的权力本身就意味着排除各州，或甚至使各州在此点上处于从属地位，那就不需要这样的限制；危险，因为引入这项限制会直接导致上述结论——如果反对者的推理正确，这本来不可能是其意图——即各州在限制不适用的一切情况下，将拥有与联邦并行的征税权。这项限制相当于律师所说的“否定中寓肯定”（negative pregnant），即否定一件事而肯定另一件事：否定各州对进出口货物征税的权力，肯定它们对其他一切物品征税的权力。[^3] 如果辩称它的用意是绝对排除各州征收前一类税，同时听任它们征收其他税但须受全国立法机关控制，那纯属诡辩。禁止性条款只是说，各州未经国会同意不得征收此类关税；如果我们按后一种意义理解，宪法就会被弄得为了一项极其荒谬的结论而引入一条正式规定，即：各州经全国立法机关同意，可以对进出口货物征税；而且它们可以对其他一切物品征税，除非受同一机关控制。如果这是本意，为什么不一开始就把问题留给原条款——即授予联邦一般征税权的条款——的所谓自然运作呢？显然，这不可能是本意，也经不起这样的解释。

至于设想州与联邦的征税权之间存在抵触，这种设想无法按排除各州所必需的那种意义成立。确实，某州可能对某一物品征税，从而使联邦再对该物品征一项税变得“不适宜”；但这并不意味宪法上不能征收进一步的税。征税额、任何一方增加征税是否适宜，彼此都属于审慎判断的问题；其中并不包含权力的直接矛盾。全国财政制度与各州财政制度的具体政策，有时可能不完全一致，可能需要相互克制。然而，能够以默示方式让渡并消灭一项先前存在的主权权利的，并不是行使权力时仅仅可能产生的不便，而是直接的宪法抵触。

在某些情况下并行管辖的必要性，产生于主权权力的划分；而一切没有被明确从各州剥夺、转归联邦的权力仍完整地保留在各州手中这一规则，并不是这种划分的理论推论，而是包含拟议宪法条款的整份文件明白承认的。我们在那里发现，尽管对各州权力有正面的授予，但在那些认为不宜由各州拥有同类权力的情况下，制宪者却最为用心地插入否定条款，禁止各州行使。第一条第十节全部由这类规定组成。这一情况清楚表明了制宪会议的意思，并从文件本身提供了一条解释规则，既证明了我所提出的主张，也驳倒了任何相反的假设。

普布利乌斯

## 注释

[^1]: 指联邦政府所在地，即后来的哥伦比亚特区。见宪法第一条第八节第十七款。

[^2]: “检查法”（inspection laws），指各州为检验出口商品质量而制定的法律；宪法允许各州在必要时为执行检查法对进出口征收规费。

[^3]: “否定中寓肯定”（negative pregnant），普通法解释术语，指一项否定表述中隐含对另一事项的肯定。此处谓禁止各州对进出口征税，反过来说明各州对其他物品有征税权。
